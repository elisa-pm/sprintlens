# Roadmap

Outcome-oriented and subject to change as feedback arrives.

| Horizon | Theme | Outcome | Items |
|---|---|---|---|
| Now (v1.0, delivered) | Foundations | A team can see delivery trends and recurring retro themes from exports | Epics A, B, C |
| Next (v1.1) | Real-world import | A Scrum Master can load a Jira export in minutes without editing files | D1, D2 |
| Later (v1.2) | Deeper flow insight | Teams see bottlenecks and verify that actions worked | D3, D4 |
| Later (v1.3) | Distribution | Anyone can run it with one command | D5 |

## Review cadence

Roadmap is reviewed at the end of each release against these questions:

1. Did the last release change how someone prepared a retrospective?
2. Which backlog items did users ask for unprompted?
3. What did we learn that changes the order of the next items?
